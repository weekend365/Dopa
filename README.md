# Dopa

Dopa는 자극적인 디지털 행동을 알아차리고 스스로 조절하도록 돕는 한국형 디지털 웰빙 서비스입니다.

- [프로젝트 개발 규칙](docs/PROJECT_RULES_KO.md)

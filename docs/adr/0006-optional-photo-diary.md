# ADR-0006: 선택적 사진 그림일기

상태: 승인됨 (2026-09-11 사용자 구현 요청). ADR-0005의 로컬 기본 사용을 유지하면서 사진 변환에만 서버 처리를 추가한다.

사진 일기는 Drift v7에 원본 이미지 바이트, 본문, 선택적 그림, 생성 작업 ID/상태/스타일 버전으로 저장한다. 날짜 unique 제약을 둔다. 별도 이미지 파일 삭제 경합을 피하려고 DB와 함께 저장하며 개인 기록함은 목록 메타데이터만 읽고 보이는 사진만 로딩한다. 성장 원장은 참조하지 않는다.

원본 저장은 네트워크와 무관하다. 외부 전송 전 선택적 동의를 받는다. 전송 내용은 EXIF가 제거된 사진, 앱의 고정 스타일, 서버가 발급한 익명 토큰뿐이며 글·활동·정원 데이터를 직렬화하지 않는다. 연령/기기 저장 동의 전에는 이미지 SDK 복구나 서버 세션을 초기화하지 않는다.

Node 24 단일 프로세스, SQLite 작업 큐, sharp, OpenAI Images edits를 개발 환경에 구현한다. Firebase 인증 SDK 도입은 이번 범위에서 제외하며 로컬 발급 Bearer를 Flutter Secure Storage로 보관한다. 공개 배포 전 attestation/남용 방지와 HTTPS, 데이터 전송 고지·스토어 선언을 검토해야 한다.

요청 ID는 클라이언트에 선기록한다. 날짜 할당/중복은 서버 트랜잭션으로 검사하고 외부 API 호출은 영속 큐에서 처리한다. 외부 호출과 DB 확정은 분산 트랜잭션이 아니므로 엄밀한 exactly-once를 약속하지 않는다. 확인 불가 작업을 자동 재시도하지 않아 중복 과금 위험을 제한한다. 삭제 tombstone은 늦게 도착한 업로드와 완료 결과를 차단한다.

이미지 공급자의 보관은 앱 서버와 별도이며 즉시 전체 삭제를 약속하지 않는다. 상세 보관/한도/실행 계약은 [서버 README](../../backend/diary/README.md)를 따른다. 키 미설정 상태에서 실 생성 품질과 비용은 검증되지 않았다.

# Dopa 디자인 규칙 — 햇살 드는 정원
상태: 현재 구현 기준 · 2026-09-11 · 사용자 승인 계획 반영

## 중심 경험
“잠깐 쉬고, 작은 일을 시작하고, 내 하루로 돌아가는 곳.”
스마트폰 사용을 줄이고 일상의 시작을 돕고 싶은 18~39세를 중심 대상으로 하며 만 14세 이상 이용 기준을 유지한다.
밝은 바탕과 읽기 쉬운 글자, 초록과 햇살색으로 편안함과 생기를 표현한다. 화면마다 중심 행동을 하나 둔다.
격려는 실제 행동을 짚고, 중단·휴식에는 실패 표현을 쓰지 않는다. 도파민 초기화·건강 개선 효과를 약속하지 않는다.
무한 피드, 자동 다음 콘텐츠, 연속 출석 압박, 보상 반복 애니메이션, 시듦·성장 차감은 없다.

## 하루 경험의 연결
2026-09-11 기능 조화 개선: 쉬기 → 작은 일 시작 → 하루 돌아보기를 중심으로 연결한다.
- 오늘의 중심 조작은 같이 시작하기와 쉬어가기다. 사진 일기는 아래쪽에 ‘오늘 기억하고 싶은 순간’으로 둔다.
- 생활 안내는 책상 한 칸 비우기, 책 한 쪽 펼치기, 미룬 일 첫 동작 하기 중 선택한다. 기본 선택은 책상이며 선택한 안내·단계는 로컬에서 복구한다. 모두 수동 4단계이며 영상 동행을 약속하지 않는다.
- 기록은 활동을 시작한 로컬 날짜와 일기에 저장된 로컬 날짜를 기준으로 묶는다. 생활 결과·집중·사진 일기를 같은 목록에서 보여주며, 미확인 활동은 이어하기로 연결한다. 날짜 내에서는 시작·작성 시각의 역순이다.
- 기록의 정원은 작은 요약으로 두고, 사진은 화면에 접근한 행만 불러온다. 저장된 사진 일기만 있어도 빈 기록 안내를 표시하지 않는다.
- 사진 일기의 중심은 순간을 저장하고 하루 기록으로 돌아가는 것이다. 그림 변환은 로컬 저장 이후 선택하는 표현 방식이며, 작성 전에는 변환 서버 상태를 노출하지 않는다.
- 휴식과 사진 일기는 성장에 연결하지 않는다. 새 생활 안내도 기존 하루 한 번의 성장 정책을 그대로 따른다.

## 컴포넌트 상태
- 버튼: 기본/눌림은 Material 상태 색상, 비활성은 onPressed=null. 로딩은 재입력을 막고 안내와 진행 표시를 제공한다.
- 입력: 기본 경계/포커스 2px/오류 메시지/비활성. 생년월일은 숫자 입력 자동 구분, 예시와 필드 오류를 제공한다.
- 선택: 선택 색상과 체크 표시, 비선택 경계, 비활성 조작 차단.
- 생활 안내: 현재 단계와 한 가지 안내만 표시. 다음은 수동 진행, 결과는 사용자 직접 선택.
- 기록 행: 종류 아이콘, 행동, 결과. 중도 종료를 완료 시간과 구분한다.
- 오류: 짧은 설명과 재시도. 빈 기록은 첫 행동으로 연결한다.
- 아이콘: 단순 Material 외곽선 중심. 장식 이모지를 기능 아이콘으로 쓰지 않는다.
개발 앱 설정 → 디자인 시스템(/design)에서 밝은/어두운 테마와 상태를 비교한다. 운영 환경에서는 갤러리를 노출하지 않는다.

## 모션과 접근성
누름 120ms, 화면 이동 240ms, 완료 반응 최대 600ms. 바운스, 반복 반짝임, 상시 흔들림이 없다.
정원은 정적 이미지다. 모션 감소 설정에서는 불필요한 전환을 제거한다.
그림은 한 문장으로 읽고 내부 장식은 제외한다. 타이머는 사용자가 접근할 때 남은 시간을 읽되 매초 live region으로 공지하지 않는다.
320/390/430 너비, 200% 글자, 밝은/어두운 테마에서 주요 조작을 스크롤로 접근할 수 있어야 한다.

## 정원 아트
고정 3:2 구도: 왼쪽 그늘 나무, 가운데 밝은 여백, 오른쪽 성장 식물.
부드러운 과슈 질감, 넓은 잎 덩어리, 둥근 돌, 낮은 풀. 흙더미·복잡한 잎맥·광택 3D·얼굴 캐릭터는 제외한다.
0·1·3·7·14·30·60·90일에 대응하는 8단계. 처음에도 완성된 풍경이며 오른쪽 식물만 변화한다.
낮/밤 16개 개별 WebP 1152×768, 합계 6MiB 이하. 밤은 청록과 달빛으로 별도 제작한다.
홈 높이 최대 220, 기록 요약은 작게. 로드 실패는 단색과 식물 아이콘으로 대체하고 행동 버튼은 유지한다.
Rive와 이전 4×2 PNG 스프라이트 계약은 폐기한다. 자산 상세는 assets/garden/README.md 참조.

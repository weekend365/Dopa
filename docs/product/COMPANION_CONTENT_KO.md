# 같이 시작하기 — 콘텐츠 제작안

2026-09-10. 모두 Dopa용 신규 원고다. 타사 영상·대사·캐릭터·UI를 참조 복제하지 않는다.
**실제 영상/녹음/출연자/음원 권리는 아직 확보하지 않았다.** 이번 앱에는 책상 안내의 텍스트 샘플 v1만 포함한다.
아래 10개는 제작 계획이며 카탈로그의 준비 완료 항목이나 판매 상품이 아니다. 표시 시간은 안내 분량이다.

## 1. 초기 10개 정의

| 콘텐츠 / 접근 후보 | 목적 | 준비물 | 행동 단계(3~5개) | 종료 문구 |
|---|---|---|---|---|
| 책상에 시작할 자리 만들기 · 2분 · 무료 | 다음 일을 놓을 작은 자리 하나 | 책상, 물건을 잠시 놓을 자리 | 컵/작은 물건 하나 옮기기 → 종이 한쪽 모으기 → 두 손 넓이 비우기 → 쓸 물건 하나 놓기 | 해낸 만큼만 남겨요. 이제 폰을 내려놓고 이어가도 좋아요. |
| 설거지 조금 시작하기 · 5분 · 무료 | 식기 몇 개부터 손대기 | 물, 수세미, 세제, 식기 놓을 자리 | 컵 하나 고르기 → 음식물 비우기 → 컵과 식기 하나 닦기 → 헹구고 물 잠그기 | 몇 개만 해도 괜찮아요. 오늘 해본 만큼 골라주세요. |
| 원룸 한 구역 정리하기 · 5분 · 무료 | 바닥의 한 구역만 비우기 | 빈 바구니/봉투(선택) | 손 닿는 구역 정하기 → 옷만 한곳 모으기 → 버릴 종이 하나 담기 → 지나갈 자리 비우기 | 방 전체를 끝내지 않아도 괜찮아요. 오늘은 여기까지 해도 좋아요. |
| 공부할 첫 페이지 펴기 · 3분 · 무료 | 읽거나 쓸 첫 행동 하나 | 책/자료, 펜(선택) | 자료 하나 꺼내기 → 시작할 페이지 펴기 → 첫 문장 읽기 → 다음 볼 곳 표시하기 | 첫 문장부터 시작한 만큼 남겨요. 더 이어가도, 여기서 쉬어도 좋아요. |
| 분리수거할 물건 모으기 · 7분 · 확장 후보 | 한 종류를 한곳에 모으기 | 수거 봉투/상자 | 빈 용기 한 종류 고르기 → 주변의 같은 종류 모으기 → 내용물 비우기 → 지역 배출 안내를 보고 둘 자리 정하기 | 오늘은 모아둔 만큼이면 괜찮아요. 배출은 준비됐을 때 해요. |
| 외출 준비 시작하기 · 5분 · 확장 후보 | 출발 전 첫 준비 | 가방, 열쇠/카드 | 입을 옷 한 벌 꺼내기 → 필요한 물건 한 곳 모으기 → 열쇠/카드 넣기 → 신발 앞까지 가보기 | 여기까지 준비한 만큼 남겨요. 출발 시점은 직접 정해도 괜찮아요. |
| 밀린 빨래 개기 · 7분 · 확장 후보 | 옷 몇 장부터 정리 | 마른 빨래, 작은 빈 자리 | 옷 세 장 고르기 → 수건/상의 하나 펴기 → 한 장씩 접기 → 접은 것 놓을 자리에 옮기기 | 남은 빨래가 있어도 오늘 접은 만큼은 그대로예요. |
| 내일 가져갈 가방 준비하기 · 5분 · 확장 후보 | 내일 필요한 것부터 담기 | 가방, 내일 쓸 물건 | 가방 열기 → 필요 없는 종이 한 장 꺼내기 → 내일 꼭 쓸 물건 하나 담기 → 열쇠/카드 자리 확인하기 | 가방을 전부 정리하지 않아도 괜찮아요. 지금 준비한 만큼 남겨요. |
| 미뤄둔 메시지 하나 답장하기 · 5분 · 확장 후보 | 답장 초안 한 문장 | 메시지를 볼 기기(앱은 내용을 읽지 않음) | 답장할 대화 하나 직접 고르기 → 첫 인사 한 줄 쓰기 → 전할 내용 한 문장 쓰기 → 읽고 전송 여부 직접 고르기 | 보내지 않고 초안만 써도 시작이에요. 내용은 Dopa에 남기지 않아요. |
| 잠들기 전 주변 정리하기 · 10분 · 확장 후보 | 쉬기 전 주변 한 부분 준비 | 물건을 둘 작은 자리 | 컵 하나 옮기기 → 바닥 물건 한 곳 모으기 → 내일 쓸 것 한 개 준비 → 조명/휴대폰 둘 자리 정하기 → 편한 곳에 앉기 | 오늘은 여기까지예요. 잠들어야 한다는 숙제는 없어요. |

진행자가 먼저 같은 작은 행동을 천천히 보여준다. 한 구역·한 물건의 범위를 유지하고 강의, 완벽한 전후 비교, 효과 보장 문구를 넣지 않는다.
무료판도 같은 음질·자막·재생 제어·접근성을 제공한다. 확장판의 존재만으로 구독 가치를 검증했다고 판단하지 않는다.

## 2. 실제 한국어 진행 대본과 촬영/음성/자막 타임라인

모든 대사는 아래 그대로 읽는 원고다. 무음 구간에는 추가 대사/음악/효과음을 넣지 않는다.
발화 구간 자막은 해당 구간에만 1~2줄씩 나눠 표시하고, 무음에는 짧은 현재 행동 문장만 남긴다.
표의 타임코드는 편집 목표다. 녹음 후 실제 발화에 맞춰 VTT/SRT와 단계 메타데이터를 다시 확정한다.
텍스트 샘플의 30초 넘김은 이 영상 편집·오디오 재생을 대체하지 않으며, 제작본은 별도 콘텐츠 버전으로 등록한다.

## 3. 공통 제작 규격 및 허락 확인

- 세로 화면에서도 손/물건/자막이 가려지지 않게 촬영하고, 큰 자막 확대·음성 전용·텍스트 전문을 함께 납품한다.
- 진행자 음성은 평상시 대화 속도, 과도한 감탄·칭찬·큰 효과음 없이 녹음한다. 배경 음악 없는 판을 기본으로 한다.
- 액션마다 단계 ID, 실제 시작/종료 시각, 말하는 구간, 기다리는 구간, 음성/영상/VTT 파일 버전·해시를 기록한다.
- 기기 회전/큰 글씨·음소거·음성만 듣기·네트워크 실패 시 대체 텍스트를 제작본과 대조한다.
- 재생 종료는 `guide_ended`, 자기보고는 별도 선택이다. 화면을 보지 못한 시간이나 건너뛴 행동을 완료로 계산하지 않는다.

- [ ] 성인 출연자의 초상·목소리·편집·광고/앱/유료 콘텐츠 이용 범위 및 보상 서면 동의
- [ ] 영상·촬영 장소·소품·배경 저작물의 이용 권리와 사적 정보 미노출
- [ ] 음악 사용 시 녹음물/작곡·실연·배포 권리 확인; 없으면 무음판 사용
- [ ] 대본·자막·번역·촬영·편집 원본의 권리 귀속 및 사용 지역/기간
- [ ] CDN 저장·캐시·오프라인 복제·접근성 변형 권리
- [ ] 납품 원본/계약/라이선스 증빙 보관과 만료·철회 시 비공개·대체·고객 안내 담당 지정
- [ ] 무료/유료 모든 자료의 음질·자막 정확도·발화 속도·무음 길이 검수
- [ ] 실제 참가자 검증 동의, 개발용 샘플 결과와 제작본 결과를 별도 표본으로 기록

완료되지 않은 체크 항목을 이미 확보했다고 앱이나 판매 화면에 표시하지 않는다.

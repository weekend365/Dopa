# 하루 한 장 그림일기 v1

승인: 2026-09-11 사용자의 “첫 구현 범위에 맞게 구현해줘”. 정원 범위에 대한 명시적 추가다.

- 기기 날짜별 사진 일기 한 개, 선택적인 본문(2,000자), 원본/그림 전환, 개인 기록함.
- Dopa 과슈 그림체 한 종. 기존 정원 아트는 색·질감 참고용이며 사진의 배경으로 이식하지 않는다.
- 원본 일기를 먼저 로컬 저장한다. 전송은 변환 버튼과 별도 사진 전송 동의 후에만 한다. 본문·성장·집중 기록은 전송하지 않는다.
- 변환 한도는 익명 서버 세션의 최초 시간대 오프셋 기준 하루 성공 한 건. 실패는 재시도 가능하지만 처리 여부 불명은 자동 재시도하지 않는다. 삭제해도 그날 사용량은 남는다.
- 하루 기록 의무·스트릭·성장 보상·재생성 뽑기는 없다. 글 수정은 제한하지 않는다.
- 서버는 사진을 재인코딩해 EXIF를 제거하고 비공개 SQLite 작업 큐에 임시 저장한다. 앱 다운로드 확인 또는 삭제 시 사진을 지우며, 미수신 사진도 24시간 후 정리한다. 공급자 보관은 별도다.
- Node 서버는 이번 개발 범위의 단일 인스턴스 서버이며 공개 운영 배포는 포함하지 않는다. HTTPS 종료, 익명 계정 남용 방지/App Check, 운영 개인정보 고지 검토는 공개 전 별도 작업이다.
- 활동 DB v6→v7은 사진 일기 테이블만 추가한다. 기존 기록과 성장에 영향이 없다.

검증/실행 방법: [서버 README](../../backend/diary/README.md). API 키 없는 환경은 실제 생성 품질·비용·지연 검증 미완료로 보고한다. 테스트 대역 결과를 실제 생성 결과로 표시하지 않는다.

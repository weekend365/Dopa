# 그림일기 v1 검증 (2026-09-11)

## 완료

- Flutter 단위/화면 테스트 **122개** 통과. 화면 320·390·430 너비, Light/Dark, 글자 100%/200%에서 사진 선택·로컬 저장 조작 확인.
- 기존 순수 도메인 **55개**, 로컬 저장소 **36개** 통과. v6→v7 추가 이전과 기존 v5 성장 이전, 하루 일기 unique, 늦은 결과와 삭제 경합, 원본 보존 검증.
- 서버 Node 테스트 **13개** 통과. 동시 요청 예약, 중복 ID, 확정 실패/불확실 결과, 최초 시간대 자정, 삭제 후 한도 유지, 소유권, 사진 재인코딩/TTL, API 전송 계약 검증.
- Android 에뮬레이터: 온보딩 → 사진 선택 → 원본 저장 → 별도 전송 동의 → 실제 로컬 HTTP 작업 큐 → 결과 다운로드/ACK → 원본 전환 → 글 수정 → 개인 기록함 → 개별 삭제 → 전체 삭제 통과.
- Android Photo Picker에서 직접 합성 테스트 이미지를 선택한 동일 통합 흐름도 통과. 사용한 임시 테스트 이미지와 테스트 서버 연결 정리.
- 테스트 입력은 Flutter 입력 대역으로 고정한다. 네이티브 IME가 주입 텍스트를 덮어쓰는 경합 때문에 저장 자체의 실패와 혼동하지 않도록 입력값/저장 완료를 함께 검증한다.
- 전체 앱 단위 테스트 LCOV(생성 파일 제외): **1,775 / 2,404줄, 73.8%**. 새 그림일기 application 계층 **117 / 137줄, 85.4%**. 통합 테스트 커버리지는 합산하지 않았다.
- 일반 `main.dart` 개발 APK를 재빌드해 에뮬레이터에 설치/실행. 테스트 대역은 일반 APK 진입점에 포함되지 않는다. 로컬 기본 서버 8787은 API 키 미설정 상태로 실행.

## 아직 검증하지 않은 항목

- 사용자가 키 설정을 나중에 하기로 선택했으므로 **실 OpenAI API 호출을 하지 않았다.** 모델 접근, 실제 생성 품질/피사체 보존/일관성, 지연, 단가, 20~30장 품질 샘플 검증은 미완료다.
- 통합 테스트 결과는 8788 테스트 서버의 WebP 재인코딩 응답이며 AI가 생성한 그림이 아니다. 그림체 구성 자체는 실제 Images edits 어댑터의 `dopa-gouache-v1` 프롬프트와 정원 아트 참고로 구현했다.
- iOS 실기기/Keychain/사진 권한 및 운영 공개 HTTPS·남용 방지·스토어 고지 검토는 별도다. 운영 배포와 서버 동기화/복원은 포함하지 않는다.

키를 나중에 연결할 때는 [서버 실행 안내](../../backend/diary/README.md)를 따른다. 프로젝트 루트에서 `tooling/start_diary_server.ps1 -PromptForKey`를 실행하면 숨김 입력으로 키를 받고 해당 개발 서버만 재시작한다.

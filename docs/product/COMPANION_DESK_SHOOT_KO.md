# 책상 세션 v2 촬영·전달 패키지

상태: 촬영 전. 촬영·본인 음성 사용 및 권리 확인은 사용자 담당이다. 실제 원본, 서명, 증빙을 수령하지 않았으며 아래 문서는 촬영 준비물이다. v1 텍스트 샘플과 기록은 그대로 유지한다.

## 준비와 구도

- 스마트폰, 흔들리지 않는 거치대, 책상, 컵 하나, 종이 몇 장, 책/노트 하나를 준비한다.
- 세로 1080p, 30fps, 일반 SDR로 촬영한다. 후면 카메라를 사용하고 초점·노출을 고정한다. 손과 책상만 보이도록 얼굴·주소·모니터·사진·알림을 프레임에서 제외한다.
- 구도 예시: 화면 위 1/3은 종이와 컵, 가운데는 두 손을 놓을 빈자리, 아래 1/3은 손이 들어오는 방향. 거치대를 책상 위쪽에 고정하고 위에서 비스듬히 내려다본다. 좌우 반전되지 않았는지 확인한다.
- 책 표지·브랜드·포스터·사진·캐릭터는 무지 종이로 가리거나 프레임에서 뺀다. 배경 음악·TV·라디오를 끈다. 손을 움직일 때의 작은 생활 소리는 남겨도 된다.
- 먼저 10초 시험 촬영을 듣고 목소리가 잘 들리는지 확인한다. 같은 장소에서 10초의 방 소리를 따로 녹음한다. 휴대폰 기본 녹음 음성도 가능하며 별도 녹음이라면 시작에 박수 한 번으로 동기를 맞춘다.

## 촬영 대본

기존 `COMPANION_CONTENT_KO.md`의 책상 대본을 바탕으로 아래 순서로 촬영한다. 시각은 편집 목표일 뿐이다. 자연스럽게 말하고 문장을 빠르게 읽어 120초에 맞추지 않는다. 장면별로 따로 촬영해도 된다. 무음 구간에는 화면을 유지하고 사용자가 따라 할 시간을 준다.

| 목표 구간 | 한국어 대사 | 손 동작 / 무음 |
|---|---|---|
| 0–8초 | 지금 책상 전체를 정리할 필요는 없어요. 시작할 작은 자리만 같이 만들어봐요. | 어질러진 책상을 고정 구도로 보여준다. |
| 8–18초 | 책상 위 컵 하나를 옆으로 옮겨볼까요? 컵이 없다면 지금 눈에 들어오는 작은 물건 하나도 좋아요. | 컵을 천천히 옆으로 옮긴다. |
| 18–30초 | 없음 | 손을 멈추고 기다린다. |
| 30–40초 | 손 닿는 곳의 종이만 한쪽에 모아봐요. 지금 분류하거나 버릴 것을 정하지 않아도 괜찮아요. | 종이를 한쪽에 모은다. |
| 40–60초 | 없음 | 사용자 행동을 기다린다. |
| 60–72초 | 두 손을 올릴 만큼의 자리를 비워볼까요? 그 자리의 물건만 잠깐 옆으로 옮겨요. | 두 손 너비를 보여주고 작은 공간을 비운다. |
| 72–90초 | 없음 | 빈 공간을 유지한다. |
| 90–102초 | 이제 하려던 일에 쓸 물건 하나를 그 자리에 놓아봐요. 책 한 권이나 노트 하나면 충분해요. | 무지 노트를 놓는다. |
| 102–112초 | 없음 | 기다린다. |
| 112–끝 | 여기까지 해봐도 좋아요. 해낸 만큼 직접 골라주세요. | 손을 편하게 놓고 2초 여유를 남긴다. |

## 원본 전달 체크리스트

- [ ] 원본 MP4/MOV를 메신저 압축 없이 전달한다. 별도 음성 원본이 있으면 함께 전달한다.
- [ ] 잘된 테이크의 파일명과 다시 찍은 구간을 간단히 적는다.
- [ ] 대사 누락, 손 동작 가림, 배경 인물·소리·개인정보가 없는지 직접 확인한다.
- [ ] 본인이 촬영했고 본인의 목소리이며, 앱 배포·상업적 사용·편집·자막·오프라인 포함 사용에 동의하는 확인을 비공개로 남긴다.
- [ ] 소품·배경 저작물 확인 결과를 남긴다. 제3자가 촬영·편집했다면 같은 범위의 허락 증빙을 확보한다.
- [ ] 계약·개인정보 포함 증빙과 원본은 공개 Git 저장소에 넣지 않는다. 비공개 보관소를 이용한다.

## 원본 수령 후 편집 담당 작업

1. 원본을 직접 보고 듣고 대사·행동·무음과 권리 확인을 대조한다. 침묵을 과하게 줄이지 않고 약 2분으로 편집한다.
2. 세로 720×1280 H.264/yuv420p, AAC 48kHz, faststart MP4로 인코딩한다. 예: `ffmpeg -i approved-edit.mov -vf scale=720:1280 -c:v libx264 -crf 24 -pix_fmt yuv420p -c:a aac -b:a 96k -ar 48000 -movflags +faststart desk_v2.mp4` (세로 원본과 편집 완료본 기준).
3. 실제 발화에 맞춰 한국어 WebVTT를 작성한다. 무음에는 자막을 지우고 긴 문장은 의미 단위로 나눈다. 실제 네 단계 시작점을 밀리초로 기록한다.
4. 완성 프레임으로 포스터 JPG를 추출한다. 세 파일 합계 30MB 이하인지 확인하고 오프라인 재생·음량·자막을 검수한다.
5. `apps/mobile/assets/companion/desk_v2.json`에 경로, 각 SHA-256, 실제 길이와 단계 시작점, 비공개 증빙의 불투명 참조를 기록한다. 검수·권리 확인 전에는 `ready`와 `rightsConfirmed`를 true로 바꾸지 않는다.

자산 항목 예시 형식은 `{ "path": "assets/companion/desk_v2.mp4", "sha256": "실제 파일의 64자리 SHA-256" }`이다. `video`, `poster`, `captions` 각각 필요하다. `Get-FileHash -Algorithm SHA256` 출력은 소문자로 기록한다. 증빙 참조에는 이름·이메일·서명·공유 토큰을 넣지 않는다.

## 비공개 권리 확인서에 필요한 항목

촬영자/음성 제공자, 확인 날짜, 원본 파일 식별, 본인 촬영 및 음성 확인, 허용 범위(앱 배포·상업적 사용·편집·자막·오프라인 복제), 제3자/소품/배경 검토, 관련 허락 문서 위치, 제한 조건을 작성한다. 이 문서는 권리를 확보했다는 증빙이 아니며 빈 확인란을 자동 승인하지 않는다.

저장소 권리 대장: 현재 영상·음성·자막·포스터 모두 **미수령/미확인**, 증빙 참조 없음, 파일 해시 없음. 원본 제공 이후에만 실제 값으로 갱신한다.

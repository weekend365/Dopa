# Dopa 현재 제품 범위 — 정원 개편
2026-09-11 사용자 승인 계획. 이전 MVP v1.2의 로그인·계획·과금·나무 렌더러 계약보다 이 문서와 DESIGN_SYSTEM_KO.md, ADR-0005가 우선한다.

- 소개 한 화면 → 연령 확인 → 기기 저장 동의 → 홈. 가입·인증 SDK 없이 무료 로컬 사용.
- 만 14세 미만 차단. 생년월일 원문은 저장하지 않고 연령 구간만 저장한다.
- 동의 전 활동 DB를 열지 않는다. 이전 사용자는 갱신 동의를 한 번 하고 기존 기록·나무 ID를 이어간다.
- 오늘/기록 2개 탭, 설정 상단. 홈 중심 행동은 같이 시작하기, 보조 1분 쉬어가기, 링크 바로 집중하기.
- 진행 중 활동은 최근 시작한 집중/생활 안내를 우선 이어간다.
- 무음 휴식: 사용자가 시작하고 언제든 종료. 타이머 숫자·배경음·알림·진동·화면 켜짐 강제 없음. 백그라운드 경과 계산, 강제 종료 후 미복구, 성장·점수 없음.
- 책상 한 칸 비우기: 약 2분 분량의 수동 텍스트 안내. 한 번에 한 단계, 중단/복구, 결과 직접 선택. 완료 후 5분 집중 또는 마치기. 자동 집중 시작 없음.
- 집중: 5/10/25/50분, 기본 10분. 선택 입력은 시작 버튼 뒤. 실제 기능은 타이머이며 앱 차단·보호 선택을 노출하지 않는다.
- 기록: 시작 날짜별 생활 결과+집중 타임라인, 작은 정원, 체크인과 이번 주 성장 요약. 실험 진행 숫자는 홈에서 제외한다.
- 정상 집중 완료 또는 생활 started/asPlanned 결과는 시작 로컬 날짜 기준 하루 최대 한 번 성장. 휴식/미확인/difficult/중도 종료는 지급·차감하지 않는다.
- 개별 생활 기록 삭제는 상세만 삭제하고 최소 성장 원장은 보존. 전체 로컬 삭제는 동의와 성장 원장까지 삭제한다.
- 기존 나무 식별자·성장일 보존. UI GardenProgress가 새로운 정원에 매핑한다.

이번 범위에 실제 사람 영상, 자연 음원, 소셜 로그인 SDK, 결제, 실제 앱 차단, 서버 동기화/복원, 운영 배포는 없다. 과거 미디어 기반 도메인과 저장 필드는 기존 데이터 호환을 위해 유지하되 기본 화면은 텍스트 안내만 제공한다.

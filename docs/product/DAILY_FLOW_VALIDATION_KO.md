# 하루 경험 연결 개선 — 2026-09-11

## 반영한 흐름
- 기록 탭: 생활 행동·집중·사진 일기를 저장된 로컬 날짜별로 통합. 날짜 내 시각 역순, 같은 날짜 제목은 한 번 표시한다. 미확인 생활 안내와 진행 중 집중은 이어하기로 연결한다.
- 사진 일기 행은 미리보기·본문 일부·상세 진입을 제공한다. 수정·삭제가 실시간 반영되며 이미지 데이터는 보이는 행에서 불러온다. 사진 일기만 있어도 빈 기록으로 취급하지 않는다.
- 같이 시작하기: 기존 책상 안내에 책 한 쪽 펼치기, 미룬 일 첫 동작 하기 추가. 4단계 수동 안내, 선택한 콘텐츠 식별자로 시작·복원·결과 문구·기록을 연결한다. 기존 책상 v1/v2 복원 계약과 성장 정책은 유지한다. DB 스키마 변경은 없다.
- 사진 일기: 오늘에서는 보조 진입점으로, 기록에서는 하루 회고로 안내한다. 저장 후 기록 복귀가 먼저 보이고 그림 변환은 선택 사항으로 둔다. 작성 전 서버 연결 실패 안내는 숨긴다.

## 검증
- Flutter 전체 테스트 137개 통과, 도메인 테스트 55개 통과, Flutter 정적 분석 문제 없음.
- 마지막 화면 간격 조정 후 기록·오늘 화면 테스트 26개 재검증 통과.
- 통합 기록: 실제 메모리 SQLite에서 날짜/시각 순서, 날짜 경계, 안내 이름, 미완료 표시, 일기 수정·삭제 스트림 확인.
- 새 안내: 선택한 콘텐츠로 진행, 다른 안내로 덮어쓰지 않고 복원, 단계 유지, 직접 결과 선택 검증.
- 기록·오늘 화면: 320/390/430 너비 × 밝은/어두운 테마 × 글자 100/200%. 새 안내는 320 너비·200%에서 선택/진행/복원/결과 조작 검증.
- Android 개발 APK 빌드, 기존 데이터 유지 업데이트 설치. 실제 에뮬레이터에서 홈, 기존 사진 일기의 기록 통합, 안내 선택 화면 확인.
- 이번 검증은 새 UX 흐름 대상이다. 실제 OpenAI 사진 변환 성공과 iOS 실기기는 별도 미검증 항목이다.

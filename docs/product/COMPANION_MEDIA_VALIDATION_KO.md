# 책상 세션 v2 구현·검증 보고

2026-09-10. **재생 연결 코드·자동 테스트 완료. 실제 제작본·권리 확보·실기기 검증 미완료.** 이전 v1 보고는 `COMPANION_VALIDATION_KO.md`에 보존한다.

## 구현

- 계정 수명의 `CompanionMediaController`와 `CompanionPlaybackPort`. 사용자 시작/복원 시에만 단일 `video_player` 엔진을 준비한다. `audio_service`는 같은 엔진의 재생/정지/종료 명령을 전달하고 `audio_session` 중단·이어폰 분리는 정지로 처리한다.
- OS 백그라운드 재생 유지, 앱 뒤로가기/나중에 이어하기 정지·저장, 재시작 시 저장 위치에서 정지 복원. 영상 종료는 결과 대기로만 전환하며 세 가지 결과를 직접 선택해야 기록된다.
- 실제 단계 시작점·WebVTT 동기화, 현재 단계 다시 듣기, 다음 단계, 자막 표시, 결과 선택, 재시도/명시적 텍스트 전환. 기록에서 안내 방식을 구분한다.
- Drift v5의 `position_ms`, `playback_revision`, `guidance_mode`는 기존 실행에 0/0/textSample 기본값을 부여한다. 위치는 5초 주기와 정지·탐색·중단·종료 시 엔진에서 읽는다. 명령 직렬화, 플레이어 세대 확인, 저장 리비전 및 확정 결과 보호를 적용했다.
- 계정 삭제/로그아웃은 재생 종료와 저장 큐 정리 후 기존 삭제 트랜잭션을 실행한다. 기존 집중·성장 데이터와 v1 샘플 흐름은 유지한다.
- 제작본 manifest는 `ready: false`, `rightsConfirmed: false`. 권리 확인 참조, MP4/VTT/포스터 해시, 총 30MB 제한, 실제 길이·단계·자막 검증을 통과해야 실행 가능하다. 운영 flavor 차단은 유지한다.

## 미완료와 실제 다음 작업

1. 사용자가 [촬영 패키지](COMPANION_DESK_SHOOT_KO.md)에 따라 본인 손·한국어 음성 원본과 비공개 권리 확인을 제공한다. 현재 실제 영상·음성·자막·포스터 파일, 자산 해시, 증빙 참조는 없다. 테스트 문자열/엔진을 실제 미디어로 계산하지 않는다.
2. 원본 수령 후 대사·행동·무음을 직접 검수하고 약 2분 편집, 720p H.264/AAC MP4, 실제 한국어 VTT, 포스터, 실제 단계 타임라인과 해시를 만든다. 편집본 총 30MB 이하를 확인한다. 개인정보/계약 원본은 공개 저장소에 넣지 않는다.
3. iOS/Android 실기기에서 비행기 모드 재생, 화면 잠금 중 끝까지 재생, 잠금 화면 재생/정지/종료, 전화/포커스 상실/이어폰 분리 후 자동 재개 없음, 다른 앱 이동, 강제 종료 후 정지 복원(마지막 체크포인트부터 최대 약 5초 반복), 잠금 중 종료 후 직접 결과 선택을 검증한다. 플랫폼 서비스 설정은 구현했으나 네이티브 빌드·실기기 재생은 이번 환경에서 수행하지 못했다.
4. 실제 영상과 긴 자막을 200% 글자·VoiceOver/TalkBack으로 확인한다. 자동 레이아웃/semantics 검사만으로 실제 스크린리더 사용성 검증을 대체하지 않는다.

결제·성장 연결·추가 콘텐츠·분석 전송·운영 공개는 이번 범위에 포함하지 않는다. SDK 결정은 [ADR 0004](../adr/0004-companion-human-media.md)에 남겼다.

검증일: 2026-09-11 · Flutter 3.47.0 / Dart 3.13.0 · Android API 35 에뮬레이터

## 자동 검증
- 순수 도메인: 55개 통과.
- Drift 저장소: 33개 통과. v1/v2/v3/v4 및 실제 v5 원장 구조에서 v6 이전, 집중·생활 결과·정원 ID·날짜 보존.
- 생활 결과 시작 날짜 지급, 자정 경계, 집중/생활 동시 완료, 결과 재시도, 성장 저장 실패 전체 롤백, 개별 삭제 후 재지급 방지와 전체 삭제를 검사했다.
- Flutter: 98개 통과. 홈 320/390/430 너비 × 밝은/어두운 테마 × 100/200% 글자, 집중 화면의 각 너비·테마·200%, 생활 안내와 기록의 작은 화면 확대, 빈 상태/오류 재시도/활동 복구를 포함한다.
- 대비: 주요 글자·버튼·오류 4.5:1 이상, 입력 경계 3:1 이상.
- 정원: 16개 WebP의 디코딩 결과 1152×768, 합계 1,659,642바이트. 실제 Flutter 정원 골든 16개 통과. 낮 초기/밤 최종 Flutter 렌더링과 전체 원본 단계 연락판을 육안 검토했다.
- 무음 휴식: 백그라운드 경과 후 복귀, 숫자 카운트다운 없음, 강제 종료를 나타내는 위젯 재생성 후 초기 상태를 검사했다.
- 로컬 사용: 동의 전 DB provider 미사용, 게스트 시작, 재실행, 기존 사용자 재동의 시 ID 보존, 전체 삭제를 검사했다.

## Android 통합 테스트
integration_test/garden_flow_test.dart를 Android 에뮬레이터에서 실행, 1개 전체 동선 통과:
소개 → 나이 확인 → 동의 → 오늘 → 휴식 시작/종료 → 책상 4단계 → 직접 결과 선택 → 5분 집중 시작 → 완료 → 날짜별 기록 → 어두운 테마 → 전체 삭제.
실제 기기 UI와 SQLite를 사용하되 메모리 DB와 전용 세션 저장소를 주입해 기존 개발 앱 기록을 보존했다.
집중 경과는 주입한 시계를 5분 이동해 검사했다. 실제 5분 대기 및 백그라운드 OS 강제 종료 테스트와는 구분한다.
휴식 1분 경과의 백그라운드 복귀는 위젯 테스트로 별도 검증했다.

## 남은 외부 검증
- iOS 실기기 렌더링·접근성·앱 생명주기 검증: 미완료. Windows 환경에서는 완료로 표시하지 않는다.
- 실제 처음 사용하는 사람 대상 탐색성 평가와 장기간 사용 동기 평가: 별도 사용자 테스트가 필요하다. 버튼 가시성과 2회 이내 진입은 자동 UI 동선으로 검사했다.
- 운영 배포, 실제 앱 차단, 결제, 소셜 인증, 서버 동기화는 이번 범위가 아니다.

## 다시 실행
프로젝트 Flutter 환경에서:
- packages/domain: dart test
- packages/local_storage: dart test
- apps/mobile: flutter test --no-pub
- apps/mobile: flutter test integration_test/garden_flow_test.dart -d emulator-5554 --flavor dev
- apps/mobile: flutter build apk --debug --flavor dev

Windows 로컬 도구 경로는 .tooling/android-env.ps1 및 .tooling/Open-Dopa.cmd를 사용한다.
개발 앱 설정 → 디자인 시스템에서 공통 컴포넌트와 밝은/어두운 테마 상태를 확인할 수 있다.
